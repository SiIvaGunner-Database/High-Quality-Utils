# High Quality Utils

A library of Apps Script functions and classes to be used in the SiIvaGunner Database project.

To add the library to a Google Apps Script project, look up the script ID "1edXoDXtDEng2e6DRVV2tzjchzhks6AZ4-p1GbKt3GnRgrDzpyiAmy7h5" in the "Add a Library" menu and then select the most recent version available.
